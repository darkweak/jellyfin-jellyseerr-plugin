Jellyseerr Requester

Titles from Jellyseerr appear in Jellyfin search, next to your library, and users can request them from any Jellyfin app.

  • SearchTitles that aren't in the library yet show up in the Movies and Shows rows.
  • Favorite to requestThe heart button on a movie, a show or a single season sends the request.
  • As the userRequests use the user's own Jellyseerr account, quotas and approvals.

Connection

The address the Jellyfin server uses to reach Jellyseerr.
In Jellyseerr: Settings, General, API Key.
The address users' browsers use for "Open in Jellyseerr" links. Leave empty to use the URL above.

Search results

Works in every app: web, Swiftfin, Android TV and mobile.
Up to this many movies and this many shows, between 1 and 50.

Requests

Users are matched to Jellyseerr by Jellyfin user ID, then by user name. When this is on, users with no match request as the owner of the API key.
Adds a Standard or 4K choice to the Request dialog in Jellyfin web. Needs a 4K server set up in Jellyseerr.

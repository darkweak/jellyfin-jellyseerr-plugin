Jellyseerr Requester

Titles from Jellyseerr or Seerr appear in Jellyfin search, next to your library, and users can request them from any Jellyfin app. Jellyfin web also gets Trending and Popular rows on the home page.

  • SearchTitles that aren't in the library yet show up in the Movies and Shows rows.
  • Favorite to requestThe heart button on a movie, a show or a single season sends the request.
  • As the userRequests use the user's own Jellyseerr account, quotas and approvals.

Users

Untick a user to turn the plugin off for them: no Jellyseerr titles in their search, no home page rows, no Request button, and they can't request or remove downloads. Jellyfin works for them as if the plugin weren't installed. Pick an age to put a user in child mode.

Child mode

Users in child mode can only request titles rated for their age. Their requests are tagged, so you can let them see only what they asked for with Jellyfin's parental control: in their user settings, Parental control, "Allow items with tags".

The stricter of this country's and the US rating is used, so one lenient rating can't let a title through. Without either: the UK rating, then the strictest found anywhere.
Some titles, often new or obscure ones, have no rating at all on TMDB.
Comma separated. Added to the movie or show in Jellyfin once it's in the library, and added back if a metadata refresh removes them.
Comma separated. Sent with the request, in addition to the server's default tags. The tags must already exist in Radarr and Sonarr. If Jellyseerr refuses them, the request is made without them and the Jellyfin log says why.

Downloads

A download is stalled when Radarr or Sonarr report a problem with it, when it hasn't progressed or is overdue by this many hours, or when nothing has been in the download queue this long after the request was approved. Titles not released yet are never stalled.

Jellyfin administrators, and users with the Manage Requests permission in Jellyseerr, can remove a download: from the Request dialog in Jellyfin web, or in other apps by removing a stalled title from their favorites. It is removed from Radarr or Sonarr and cleared in Jellyseerr, so it can be requested again. For a show with seasons already available, only the open requests are cancelled.
